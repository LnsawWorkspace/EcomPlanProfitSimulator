# 支出清单样例（方案参数 · 每单 / 部分订单 / 固定支出）

> 用途：填写方案参数「每单支出 / 部分订单支出 / 固定支出」三个模块时，参考常见的支出项目、成本类型与税率。
> 站点模型见 `references/planParams.md`；脚本写参命令见 `scripts/plan_params_ops.js`（`--expense` / `--expense-mn` / `--expense-fixed`）。
> 本文是**样例不是定论**——同一类项目在不同平台/类目/计费方式下税率可能不同，以实际取得的发票税率为准。

## 0. 三个模块怎么分（先分清再选）

| 模块 | 判定标准 | 特有字段 | 典型项目 |
|------|---------|---------|---------|
| **每单支出**（ExpensePerOrder） | **每一单都必然产生** | 无（每单必出） | 快递运费、包装费、平台扣点、运费险 |
| **部分订单支出**（ExpenseMNPerOrder） | **只有部分订单才产生** | **订单比例%** + **行内退款率** | 花呗/信用卡手续费、小额退款补贴、加急运费 |
| **固定支出**（ExpenseFixed） | **固定金额，不随单量变化**（按月/按年） | 无退款、无回收率、无含税/不含税 | 店铺月租、软件订阅、水电人工 |

**判定口诀**：每单都出 → 每单支出；有的单才出 → 部分订单支出（要填"订单比例"）；不看单量固定出 → 固定支出。

---

## 1. 每单支出（ExpensePerOrder · 每单必有）

> 字段：名称 / 金额或百分比 / 成本类型(num金额 | per按售价%) / 进项税率% / 售前回收% / 售中回收% / 售后回收%
> per 类型还要选 base（目前只有"售价"）与 含税/不含税。

| 项目 | 成本类型 | 常见金额/比例 | 进项税率 | 回收率参考 | 说明 |
|------|---------|--------------|---------|-----------|------|
| 快递运费 | num | 3~5 元/单 | 6%（物流辅助）或 9%（运输） | 50-50-50 | 最普遍，含偏远加价 |
| 包装材料（纸箱/气泡袋/封箱带） | num | 0.5~2 元/单 | 13%（货物） | 50-50-50 | 量大可谈价 |
| 平台技术服务费 / 类目扣点 | per | 0.5%~5%（按售价） | 6%（现代服务） | 0-0-0 | 拼多多/京东等平台抽成，一般走 per |
| 平台佣金（京东POP等） | per | 1%~10%（按售价） | 6% | 0-0-0 | 按成交额比例，多为 per |
| 运费险 | num 或 per | 0.3~1 元/单 或 0.1%~0.5% | 6%（保险服务） | 0-0-0 | 有"包运费险"和"买家自购"两种口径 |

**每单支出不要放**：只有部分订单产生的项目（放部分订单支出）；按月固定的项目（放固定支出）。

---

## 2. 部分订单支出（ExpenseMNPerOrder · 部分订单才有）

> 字段：名称 / 金额或百分比 / 成本类型 / **订单比例%** / 进项税率% / **行内退款率 售前% 售中% 售后%** / 行内回收率% / base+含税（per 时）
> ⚠ 退款率是**行内单独填**的（区别于目标模块的方案级退款）；订单比例 = 会发生这笔支出的订单占比。

| 项目 | 成本类型 | 常见金额/比例 | 订单比例 | 进项税率 | 行内退款参考 | 说明 |
|------|---------|--------------|---------|---------|-------------|------|
| 花呗 / 信用卡手续费 | per | 0.6%~1%（按售价） | 20%~40% | 6% | 1-1-0 | 买家用信用支付才产生，常见 30% 左右 |
| 小额退款补贴 / 仅退款补偿 | num | 2~5 元 | 5%~15% | 6% 或 13% | 0-0-100（售后单） | 退款订单才产生，售后退款率常设高 |
| 顺丰 / 加急运费差价 | num | 5~10 元 | 3%~10% | 6% 或 9% | 按实际 | 客户指定时效才产生 |
| 礼品包装 / 定制服务 | num | 3~8 元 | 1%~5% | 13% | 按实际 | 送礼场景订单 |
| 分期免息补贴 | per | 0.3%~1%（按售价） | 5%~15% | 6% | 按实际 | 平台大促分期 |

**部分订单支出不要放**：每单都有的项目（放每单支出）；按月的固定费用（放固定支出）。订单比例忘了填=这笔支出永远不生效。

### ⚠ 满减 / 优惠券 / 平台补贴：不是支出，是售价调整

**满减、优惠券（商家券）、平台补贴这类项目改变的是买家实际支付金额 = 影响销售额（收入端），不是成本支出**，不要放进任何支出模块——记成支出会让成本虚高、利润失真。

- 这类玩法的本质是**渠道售价变了**（到手价 = 标价 − 满减/券/补贴）。ecomplan 的语义是「一个方案 = 一条逻辑渠道」，**应把它当成一个新的渠道（新方案）**：
  - 新建一个方案，如 `拼多多-满减活动` / `京东-百亿补贴` / `直播-平台券`；
  - 售价填**实际到手价**（如标价 99.9、满减 20 → 售价 79.9），其余成本参数照旧填。
- 什么时候仍是"支出"？只有**平台向你收的钱**（佣金、扣点、手续费、运费）才是支出；**你让利给买家的钱**（满减、券、补贴）是收入调整，走新渠道。
- 判断口诀：**钱进了谁的口袋**——平台/快递/服务商拿走 → 支出；买家少付了 → 售价调整（新方案）。

## 3. 固定支出（ExpenseFixed · 固定金额不随单量）

> 字段：名称 / 金额或百分比 / 成本类型 / 进项税率%
> ⚠ **没有**退款率、**没有**回收率、**没有**含税/不含税控件（HTML 已确认），填了也会被忽略。

| 项目 | 成本类型 | 常见金额 | 进项税率 | 说明 |
|------|---------|---------|---------|------|
| 店铺月租 / 平台年费 | num | 300~1000 元/月（年费折月） | 6% | 拼多多/京东店铺基础费 |
| ERP / 打单软件订阅 | num | 几十~几百元/月 | 6%（软件服务） | 管家婆/旺店通等 |
| 仓储 / 水电 / 场地 | num | 按实际 | 6%（服务）或 13%（货物） | 有实体库房才填 |
| 人工（客服/打包） | num | 按实际 | —（工资无进项发票，可不填税率） | 建议按实际月薪折算 |
| 商标 / 版权 / 质检年费 | num | 按实际 | 6% | 类目资质类 |

**固定支出不要放**：随单量变化的项目（放每单/部分订单）。它是"无论卖多少单都要掏的钱"，用于摊薄到每单。

## 4. 填法速查（税率 / 成本类型 / base）

### 税率怎么猜（大概率）
- **6%** = 服务类：技术服务费、佣金、手续费、软件订阅、保险、广告
- **9%** = 运输类：快递运输（如果开运输发票）
- **13%** = 货物类：包装材料、商品采购、赠品成本
- 拿不准默认 **6%**（电商支出绝大多数是服务业发票）

### 成本类型怎么选
- 按**每单固定金额**（元）→ `num`
- 按**售价百分比**（%）→ `per`，必须同时填 base=「售价」+ 含税/不含税
- 固定支出通常是 `num`（按月固定金额），少见 per

### base 与含税
- per 类型的 base 目前只有「售价」一个选项（源码 options=["-","售价"]）
- 含税 = 以含税售价为基数；不含税 = 换算为不含税收入做基数。商家视角默认**含税**，除非合同写明不含税。

### 回收率（退款损失能回来多少）
- 商品/赠品/每单支出都有回收率（售前/售中/售后三档）
- 衣服类目参考：商品 80-80-60，运费/包装 50-50-50，平台扣点/手续费 0-0-0（退不回）
- 意义：成本 1000、回收率 80% → 能回 800、损失 200（见站点官方说明）

## 5. 与脚本命令对应（填完直接写参）

```bash
# 每单支出：--expense "名称,金额,num|per,进项税率%,售前回收%,售中回收%,售后回收%[,含税|不含税]"
"$N" plan_params_ops.js set "拼多多推广" --group "睡衣+睡裤" \
  --expense "快递运费,3,num,6,50,50,50" \
  --expense "平台技术服务费,1,per,6,0,0,0,含税"

# 部分订单支出：--expense-mn "名称,金额,num|per,订单比例%,进项税率%,售前退款%,售中退款%,售后退款%[,回收%...][,含税|不含税]"
  --expense-mn "花呗手续费,0.6,per,30,6,1,1,0,50,50,50,含税" \
  --expense-mn "小额退款补贴,2,num,10,6,0,0,100,50,50,50" \

# 固定支出：--expense-fixed "名称,金额,num|per,进项税率%"
  --expense-fixed "店铺月租,300,num,6" \
  --expense-fixed "ERP软件订阅,50,num,6"
```

> 同名行 = 修改，不同名 = 新增；`--expense-del/--expense-mn-del/--expense-fixed-del "名称"` 删除单条；`"旧名>新名,..."` 改名。
